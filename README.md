# CPU Zamanlama Algoritmaları Simülatörü

BİM 361 İşletim Sistemleri dersi dönem projesi.

## Ne yapar?
Verilen işlem listesini FCFS, SJF, Round Robin ve Multilevel Queue
algoritmalarıyla zamanlar, Gantt şeması çizer ve algoritmaları
karşılaştırır.

## Gereksinimler
- Python 3
- Matplotlib (pip install matplotlib)
- Tkinter (Python ile birlikte gelir)

## Nasıl çalıştırılır?
1. Repoyu indirin.
2. Klasörde terminal açıp şunu yazın:
   python main.py

## Girdi formatı (islemler.txt)
Her satır: ad,varış zamanı,çalışma süresi,öncelik
Örnek: P1,0,8,1
